# website_SMP-ALAM-EXCELLENTIA-PAMEKASAN

Website Profil Resmi dan Portal PPDB **SMP ALAM EXCELLENTIA PAMEKASAN (Yayasan Insan Kamil)**.

## Fitur Utama
- **Identitas Sekolah & Logo Resmi**: Logo resmi SMP Alam Excellentia Pamekasan.
- **Visi & 5 Misi**: Visi dan 5 Misi strategis pendidikan sekolah alam.
- **Falsafah**: *GROWING TOGETHER WITH EXCELLENT* & *PENGALAMAN ADALAH GURU TERBAIK*.
- **Informasi Guru & Fasilitator**: Profil tenaga pendidik dengan panel edit khusus Admin Utama.
- **Sistem Login**:
  - **Admin Utama**: Manajemen konten, verifikasi pembayaran, dan pengelolaan guru.
  - **Tamu Pengunjung**: Akses *view-only* dan konsultasi langsung via WhatsApp.
- **PPDB (Pendaftaran Siswa Baru)**:
  - Alur pendaftaran terstruktur.
  - Fitur kirim bukti transfer pembayaran administrasi (membuka formulir pendaftaran).
  - Formulir pendaftaran siswa baru & notifikasi verifikasi real-time di Dasbor Admin.
- **Layanan Konsultasi WhatsApp**: Konsultasi langsung ke nomor panitia/admin terdaftar.

## Cara Menjalankan Secara Lokal
```bash
npm install --legacy-peer-deps
npm run dev
```
Akses di browser: `http://localhost:3000`
